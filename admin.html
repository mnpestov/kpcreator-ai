Админка проекта kpcreator.ru

Эта страница — шпаргалка для администратора проекта. Тут собраны основные команды и процессы по управлению сервером.

1. Проверка состояния

  • Проверить работу фронтенда: https://kpcreator.ru
  • Проверить API: https://kpcreator.ru/api/healthz
  • Проверить процессы: pm2 list
  • Логи API: pm2 logs kurgi-api --lines 100

2. Бэкапы базы данных

Автоматический бэкап выполняется ежедневно в 03:00. Файлы хранятся в /var/backups/pg (хранятся 14 дней).

  • Создать бэкап вручную: 
    pg_dump -h 127.0.0.1 -U kurgidb -d kurgikp | gzip > /var/backups/pg/dump_$(date +%F).sql.gz

3. Обновление кода

Backend

cd /var/www/kurgi/Kurgi_KP_backend
git pull origin main
npm install --production
pm2 restart kurgi-api

Frontend

cd /var/www/kurgi/Kurgi_KP_frontend
git pull origin main
npm install
npm run build
rm -rf /var/www/kurgi/frontend_build/*
cp -r build/* /var/www/kurgi/frontend_build/
sudo systemctl reload nginx
Важно: перед деплоем убедись, что база данных в актуальном состоянии (бэкап сделан).

4. SSL-сертификат

  • Проверить срок действия: sudo certbot certificates
  • Принудительно обновить: sudo certbot renew --force-renewal

5. PM2

  • Сохранить процессы: pm2 save
  • Автозапуск при старте: pm2 startup
  • Лог-ротация: настроен модуль pm2-logrotate

6. Чеклист после обновления

  • Фронтенд открывается без ошибок
  • API отвечает на /api/healthz
  • Проверить работу CRUD-операций КП
  • Проверить генерацию PDF
  • Проверить адаптивность интерфейса

Последнее обновление инструкции: сентябрь 2025.
